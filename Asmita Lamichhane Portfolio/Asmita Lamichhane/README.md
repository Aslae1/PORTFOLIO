# Asmita Lamichhane, Portfolio

A responsive portfolio built with HTML, CSS and vanilla JavaScript. GitHub: [Aslae1](https://github.com/Aslae1).

## What is on the site
- **About, skills and education:** study details, languages and a full skills list from my CV.
- **Featured work:** Canvaru, CityMoto, NJFON, The Last Glitch and AIRWAY, each with highlights and its own case study page.
- **Achievements:** 1st place at KOPILA (January 2025), a 2nd place college hackathon and The Glitch international Solana hackathon.
- **Creative section:** flower and heart illustrations plus interactive manga characters (Mika and Ren). More fun projects live in [Vibe-Projects-](https://github.com/Aslae1/Vibe-Projects-).
- **Resume:** `resume.html` is the web CV and `Asmita-Lamichhane-CV.pdf` is the download.
- Light and dark themes, keyboard-friendly navigation and reduced-motion support.

## Edit your details
All text for projects, contact info and creative items is in the `CONFIG` object at the top of `script.js`.

## Run locally
```bash
python -m http.server 5173
```
Then visit `http://localhost:5173`.

## Publish with GitHub Pages
Upload this folder to a repository, then choose **Settings > Pages > Deploy from a branch > main > /(root)**.

How I design a page

  1. Discover

    Who is this for, and what do they need to get done? I start with the brief, the audience and a few real examples.

  2. Define

    Turn what I learned into one clear problem to solve and a short list of what the page must do.

  3. Design

    Sketch, wireframe, then pick colour, type and spacing as one small system.

  4. Deliver

    Build it, test it on a phone, check keyboard and contrast, and change what feels awkward.

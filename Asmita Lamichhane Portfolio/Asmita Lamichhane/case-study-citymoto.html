Web Project · Interface Design

CityMoto

CityMoto was my first client project: a web-based vehicle rental platform.

RoleFirst client project
FocusWeb experience
StackHTML · CSS · JavaScript
DeliveryBuilt through to deployment

Project context

The project was designed to help people browse vehicles, check availability and book rentals through a web-based workflow. The aim was to make the purpose of the site and its navigation clear at a glance.

Design priorities

Key interface priorities include clear page hierarchy, readable content, responsive layout and consistent actions. These foundations help visitors understand what the site offers and where to go next.

Implementation

I handled requirements gathering, interface design, development and deployment. Source code is available on my GitHub profile.

What I learned

CityMoto taught me how a real brief shapes every decision: gathering requirements first, then balancing visual presentation with straightforward navigation, and finally deploying so the client could use it.

Next steps

A useful next iteration would validate the main user flow with target users, document the final feature set and add real screenshots of the current build.

Canvaru

Canvaru is a doodle-recognition project that predicts a label from a small hand-drawn image. It explores a simple human–computer interaction: draw something, then let a model make its best classification.

RoleModel training and evaluation
DataQuick, Draw! doodles
StackPython · TensorFlow · CNN
StatusAcademic project

The problem

A sketch is an informal visual input. This project explores whether a compact image classifier can recognize common doodle categories from low-resolution grayscale images.

Approach

The dataset uses 28 × 28 grayscale images from six classes: apple, cat, flower, house, star and tree. A convolutional neural network (CNN) learns visual patterns from the training examples and predicts one of the six labels.

Evaluation

The recorded test set contains 3,150 examples. The model reached 94.48% test accuracy, with a weighted F1 score of 0.9449. These figures describe this test split; they do not guarantee the same performance on every drawing or dataset.

What the results suggest

House was the strongest class in the reported results (F1 0.9840), while cat was the most challenging (F1 0.9050). This shows why per-class results and a confusion matrix add context beyond accuracy alone.

What I learned

The project gave me practice preparing image data, training a CNN, evaluating per-class performance and interpreting a confusion matrix.

Next steps

A useful next iteration would test drawings from people outside the training dataset, inspect common misclassifications and connect the trained model to a simple browser interface.
